# Requirements

## Feature Request from Registrar

The system should determine whether a student can register for a course.

A student may register only if:
- the course is not full,
- the student has completed the prerequisite,
- adding the course would not put the student over 18 credit hours.

If registration succeeds, the course credit hours should be added to the student’s current credit hours.

If registration fails, the student’s credit hours should not change.

The system should return a clear message explaining the registration result.
